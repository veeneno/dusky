baixar o didiscord

O app pro computador: compartilha a tela pela placa de vídeo (sem pesar no jogo), pega o som de um app só, avisa quando te chamam e se atualiza sozinho.

como instalar

  1. Baixa o instalador e abre.
  2. Se aparecer "O Windows protegeu o computador", clica em Mais informações e depois em Executar assim mesmo — o aviso aparece porque o app não tem assinatura paga da Microsoft.
  3. Escolhe onde instalar e pronto: o didiscord abre direto no servidor.

As próximas versões chegam sozinhas: o app baixa em segundo plano e pergunta se quer reiniciar.

  1. Baixa o arquivo .AppImage.
  2. Deixa ele executável: botão direito → Propriedades → "permitir executar", ou no terminal: chmod +x didiscord-*.AppImage
  3. Abre com dois cliques (ou ./didiscord-*.AppImage). Pra ele aparecer no menu de apps, dá pra usar o Gear Lever ou o AppImageLauncher.

É o jeito recomendado no Linux: se atualiza sozinho, sem pedir senha.
Compartilhar a tela pela placa no Wayland (Hyprland, GNOME, KDE) precisa do GStreamer:
Arch/CachyOS: sudo pacman -S gst-plugin-pipewire gst-plugins-bad gst-plugins-ugly
Ubuntu/Debian: sudo apt install gstreamer1.0-pipewire gstreamer1.0-plugins-bad gstreamer1.0-plugins-ugly

  1. Baixa o arquivo .deb.
  2. Instala pelo terminal: sudo apt install ./didiscord-*.deb
  3. O didiscord aparece no menu de apps.

Também se atualiza sozinho, mas pede a senha de administrador a cada versão nova. Sem esse incômodo, use o AppImage.

Prefere não instalar nada? Dá pra usar direto no navegador: entrar no didiscord.
No celular, use pelo navegador mesmo.
